# Projeto Power BI - Modelo VENDAS

Este repositório contém uma cópia local do modelo semântico VENDAS.

## REGRAS OBRIGATÓRIAS

1. Trabalhe somente nos arquivos locais deste repositório.

2. Nunca conecte diretamente ao Power BI Service.

3. Nunca utilize o endpoint:
   powerbi://api.powerbi.com/

4. Nunca publique alterações no Power BI Service.

5. Nunca execute alterações via XMLA.

6. Nunca utilize "Save to DB" do Tabular Editor.

7. Nunca altere modelos semânticos remotos.

8. Você pode analisar e modificar o arquivo VENDAS.bim local.

9. Antes de excluir tabelas, colunas, medidas, relacionamentos,
   roles ou outras estruturas, solicite confirmação.

10. Não execute git push.

11. Não faça merge na branch master.

12. Não execute:
    git reset --hard
    git clean
    git push --force

13. Após qualquer alteração, informe:
    - quais objetos foram alterados;
    - quais medidas foram alteradas;
    - quais arquivos foram alterados.

14. As alterações devem permanecer somente na branch de trabalho.

## Objetivo

O Claude deve atuar como assistente de desenvolvimento do modelo
semântico Power BI, realizando alterações somente na cópia local.

A publicação no Power BI será realizada manualmente pelo responsável
após revisão das alterações.
